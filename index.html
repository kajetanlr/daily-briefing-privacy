Daily Briefing: Privacy Policy

Daily Briefing is a personal, non-commercial tool used only with its developer's own and family members' Google accounts. It is not offered to the public.

What it accesses

With the account owner's consent, it requests read-only access to Gmail (gmail.readonly) and Google Calendar (calendar.readonly). It cannot send, delete, move, label or mark email as read, and cannot change calendars.

How data is used

Message headers, short text excerpts and calendar events are read once a day to produce a private summary email sent only to the account owner. Data is processed in memory and is not stored, sold or shared, except that text excerpts are sent to an AI service to produce the summary.

Google API Services User Data Policy

Daily Briefing's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
